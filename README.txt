# Vijay Raju - Personal Portfolio

## Run locally
1. Extract the zip.
2. Open the folder in VS Code and run index.html with Live Server (or double-click index.html).
3. Internet is required for Google Fonts, Font Awesome and Devicon icons.

## Folder structure
index.html, style.css, script.js
assets/vijay-profile.jpg  (hero photo)
assets/favicon.png        (browser tab icon, cropped from the photo)

## Confirm before publishing
- Name: the site says "Vijay Raju", but the email and LinkedIn say "bablu mungara". Confirm the correct name
  (search "Vijay" in index.html and replace).
- Project cards: replace the generic titles/descriptions with real project details and add GitHub links.
- Training: add the institute name and dates if needed.
